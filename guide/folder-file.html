03프로젝트 폴더 이름

[ARTIST]ProjectName
[ARTIST] 아티스트·배우 이름, 영문 대문자ProjectName 연도 + 프로젝트명
  • 배우·아티스트 이름은 모두 영문으로 써요. 한글 이름을 쓰지 않아요.
  • 폴더 이름에는 프로젝트명을 줄이지 않고 전부 써요.
이렇게[JUNGHAEIN]2027SG_COMESTAY영문 이름, 연도 4자리
이렇게 하지 않기[정해인]27SG COMESTAY한글 이름, 연도 2자리, 띄어쓰기

04파일 이름

[Artist]ProjectName_Item(yymmdd)V2
Item 품목명(yymmdd) 작업 날짜 6자리V2 같은 품목·같은 날짜 파일이 여러 개일 때만
  • 띄어쓰기 대신 단어 첫 글자를 대문자로 구분해요. 예: WishingYouABrightFuture
  • 한글은 되도록 쓰지 않아요.
  • 마침표 . 쉼표 , 물음표 ? 느낌표 !는 쓰지 않아요. 하이픈 - 언더바 _ 괄호 ( )만 써요.
  • 프로젝트명이 길면 파일 이름에서는 줄이거나 빼요.
  • 같은 품목을 같은 날짜에 여러 개 저장할 때만 날짜 괄호 바로 뒤에 V1 V2를 붙여요. 하나뿐이면 붙이지 않고, 앞에 하이픈이나 언더바를 넣지 않아요.
이렇게[P1H]2027SG_Calendar(261112)V2.ai긴 프로젝트명은 생략, 같은 날 두 번째 파일이라 V2
이렇게 하지 않기P1H 캘린더 최종_수정.v2!.ai띄어쓰기, 한글, 마침표·느낌표, 날짜 없음

05일러스트 파일 저장·전달

Final에 넣거나 외부에 공유하는 일러스트 파일은 세 개로 저장하고 전달해요. Backup 폴더는 원본 하나만 저장해도 돼요.

AI 원본[GD]2027FANKIT_Tshirt(261112)V2.ai텍스트를 깨지 않은 수정 가능한 원본
AI 아웃라인[GD]2027FANKIT_Tshirt(261112)V2_Outline.ai텍스트를 윤곽선으로 만든(깬) 파일. 인쇄소 전달용
PDF[GD]2027FANKIT_Tshirt(261112)V2.pdf확인·컨펌용

06저장·전달 전 체크리스트

  • 인디자인·일러스트 파일의 링크 이미지가 모두 제대로 연결돼 있는지 확인했나요?
  • 파일 이름에 띄어쓰기, 한글, 마침표, 쉼표, 물음표, 느낌표가 없나요?
  • 날짜(yymmdd)가 붙어 있나요? 같은 품목·같은 날짜 파일이 여러 개라면 V1, V2로 구분했나요?
  • 일러스트 파일은 원본, _Outline, PDF 세 개를 다 만들었나요?
  • 맞는 폴더(Final / ToClient / Sample)에 넣었나요?
